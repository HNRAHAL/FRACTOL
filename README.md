Description:   
****************
- The project is called Fract-ol
- Its main objective is to draw a fractal and display it on a window on the computer
- fractal is basically an object or a certain drawing that has sub pictures of that main picture like mandelbrot and julia sets
- Mandelbrot and julia follow certain mathematical equations know as complex numbers
- a complex numbers is basically a number consisting of a real and imaginary number which is a dot on the coordinate graph
- a repeated execution of the sequence of the mandelbrot equation or the julia set allows certain patterns to be drawn on the window in addtion to colouring certain parts of the drawing to see its patterns.

****************
instructions:
****************
- make
- valgrind ./fractol mandelbrot or ./fractor julia "real number" "imaginary number"
